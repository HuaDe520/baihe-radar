# 训练报告

- 数据：7370 个主角名（百合 2458 / 纯爱 2465 / 言情 2447），来自晋江文学城作品库主角名字段
- 词表：2008（pad + unk + 2006 个汉字）
- 划分：train 5896 / val 737 / test 737
- 模型：字符 embedding 28 + conv k=1/2/3 (32/40/40) + ReLU + max/mean 双池化 + FC64 + 输出 3
- 参数规模：约 7.7 万
- 测试集准确率：**42.20%**（多数类基线 33.45%，随机基线 33.3%）
- macro-F1：0.4211
