# v2 双头模型训练报告

- 数据：18113 个主角名（百合 6047 / 纯爱 6075 / 言情 5991）
- 词表：2717；划分 train 14489 / val 1812 / test 1812
- 结构：emb 32 + pos 8 → conv k=1/2/3 (64/96/96) + BN → ReLU → max/mean pool
  → 拼首字/末字 emb（576 维）→ FC 128 → 双头（3 分类 + 2 分类）
- 参数：184,037
- 三分类：测试 acc **45.75%**（多数类基线 33.54%，随机 33.3%），macro-F1 0.4395
- 二分类（百合 vs 非百合）：acc 66.17%，**平衡准确率 58.90%**，macro-F1 0.5915，混淆 [[tn,fp],[fn,tp]]=[[975, 232], [381, 224]]
- 混淆矩阵（3 类，行=真实）：[[337, 180, 88], [165, 358, 85], [234, 231, 134]]
- 最佳 epoch：18（验证 acc3 45.53% / bal2 59.31%）

> 说明：名字与频道取向只有弱相关，3 分类接近「性别用字统计」；二分类平衡准确率更能反映真实可分性。
> 纯娱乐向玩具，不构成对真实个人性取向的判断。
